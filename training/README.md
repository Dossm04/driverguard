# Обучение DriverGuard

Четыре класса: `phone`, `cigarette`, `seatbelt_on`, `seatbelt_off`.
Обученные веса и исходные изображения в репозитории не хранятся.

## Какой блокнот открыть

- [DriverGuard_FAST_30min.ipynb](DriverGuard_FAST_30min.ipynb) — первый запуск:
  бюджет основной тренировки около 30 минут. Установка библиотек, скачивание,
  проверка данных, оценка и экспорт занимают дополнительное время.
- [DriverGuard_Colab_FIXED.ipynb](DriverGuard_Colab_FIXED.ipynb) — полный вариант обучения.

В приватном репозитории проще скачать выбранный файл, открыть Google Colab и выбрать
**Файл → Загрузить блокнот**. Затем **Среда выполнения → Сменить среду выполнения → T4 GPU**.
Если Colab сообщает о лимите GPU, обучение на T4 пока недоступно; загрузка на GitHub
этот лимит не снимает. Не запускайте оба блокнота одновременно.

## Порядок работы

1. Запустите первую ячейку. Она должна подтвердить наличие GPU.
2. Добавьте собственный ключ Roboflow в секреты Colab под именем `ROBOFLOW_API_KEY`
   и разрешите блокноту доступ к нему. Быстрый блокнот также умеет запросить локальный
   файл `ROBOFLOW_KEY_PRIVATE.txt`. Ключ не вставляйте в исходный код и не загружайте в GitHub.
3. Запустите скачивание данных. Используется Roboflow PFE:
   workspace `pfe-lcrvh`, project `pfe-scklc`, version `1`.
   Доступ и условия использования набора проверяются в вашем аккаунте Roboflow.
4. Выполните подготовку и просмотрите примеры разметки. Дубликаты и три явно перечисленных
   повреждённых файла исключаются с записью в аудит; другие ошибки останавливают проверку.
5. Запустите обучение, затем оценку и экспорт по порядку. Таймер ожидания ключа
   не является временем обучения. Обучение видно по эпохам и значениям loss.
6. Скачайте получившийся ZIP результата и сохраните его отдельно от исходников.
   Если подключён Google Drive, блокнот сохраняет резервные копии туда.

## Подключение результата

В корне клонированного проекта, в Python-среде с `numpy` и `onnxruntime`:

```powershell
python training/install_candidate.py --bundle "C:\path\result.zip"
```

Импорт проверяет хеш, классы, форму входа/выхода ONNX и наличие отчётов, после чего
готовит модель **со статусом candidate** для браузера. Затем пересоберите web:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File infra/start-demo.ps1 -Rebuild
```

Успешный импорт не подтверждает точность на новых водителях. Для этого нужны отдельные
видео, ручная разметка ожидаемых событий и отчёт об ошибках. Нельзя утверждать, что
телефон, курение и ремень проверены в реальной эксплуатации, только по результатам обучения.

## Файлы

- `driverguard_data.py` — аудит, очистка и приведение разметки.
- `install_candidate.py` — проверка пакета результата и подготовка браузерной модели.
- `score_video_report.py` — оценка отчёта по видео; параметры: `python training/score_video_report.py --help`.

Используйте свежую загрузку блокнота из этой папки. Секреты, данные и результаты
обучения исключены из Git; выходные данные ячеек опубликованных блокнотов очищены.
