# DriverGuard: простой вариант для защиты и развитие пилота

Решение от 7 октября 2026. Это описание целевой идеи и текущего прототипа, а не отчёт полевых испытаний.

## Идея

DriverGuard — помощник водителя, который анализирует изображение прямо на устройстве
в автомобиле. При длительном закрытии глаз он подаёт звуковое предупреждение и сохраняет
событие. Интернет для локального анализа не требуется. Когда связь появляется,
приложение передаёт накопленные события в панель координатора. Память под обычные
видеозаписи ограничена: старые фрагменты удаляются, освобождая место для новых.

Для первой демонстрации достаточно Android-телефона с его собственной камерой,
держателя и зарядки. Для следующего этапа можно добавить направленную на водителя
ИК-камеру Hikvision: она передаёт изображение по локальной сети, а Android выполняет анализ.
Запись исходного потока можно вести на карту памяти самой Hikvision.

## Сравнение

| Вариант | Что требуется | Текущий статус | Вывод |
|---|---|---|---|
| Android + его камера | Телефон, держатель, зарядка | APK 0.2.0 собран; модели включены, физический тест ещё нужен | Наименьше шагов и покупок для защиты |
| Android + Hikvision | Камера, её питание, локальная сеть; для кабеля — совместимый Ethernet/PD-адаптер | RTSP-клиент реализован; связка с физической камерой не проверена | Следующий этап для салона и ИК-съёмки |
| iPhone + его камера | Имеющийся iPhone, держатель, зарядка | PWA с подготовкой офлайн; физический Safari-тест ещё нужен | Резерв, если Android не найдётся; не повторяет все функции Android |
| iPhone + Hikvision | Камера, питание, локальная сеть/Lightning Ethernet и новое iOS-приложение | Нативного проекта и сборки пока нет | Больше работы перед защитой; Mac нужен для прямого пути сборки/установки |

«Самый простой» здесь — инженерная оценка по готовности кода, числу устройств и установке,
а не измеренный рейтинг качества камер. Если подходящий Android уже можно одолжить,
его использование исключает покупку внешней камеры для первого показа.

## Что действительно есть в Android 0.2.0

- Локальная модель MediaPipe для лица и временное правило длительного закрытия глаз.
- Предупреждение, SQLite-журнал, CSV-экспорт.
- Включаемая запись собственной камеры короткими MP4-фрагментами, ротация по времени/месту.
- Очередь событий закрытия глаз, привязанная к серверу и водителю, подтверждение при отправке.
- Локальный RTSP/TCP H.264 для внешней камеры.
- Исследовательские открытые модели ремня и сигареты, выключенные по умолчанию.

Это собственное приложение DriverGuard с интеграцией открытых моделей. Не следует
представлять открытые веса как полностью обученную нами четырёхклассовую модель.
Телефон у уха пока не распознаётся. Сигарета в кадре не доказывает курение.
Точность ремня/сигареты, ИК, нагрев и работа на реальном телефоне ещё требуют испытаний.

## Честный сценарий защиты — около минуты

1. Показать приложение на Android и выключенный интернет. Начать наблюдение.
2. Сидя на месте, показать обычное моргание, затем закрытие глаз примерно на две секунды.
3. Показать предупреждение и новую запись с текущим временем в локальном журнале.
4. Если включена запись — остановить и открыть завершённый фрагмент.
5. При доступном сервере: восстановить связь, отправить очередь, показать исходное событие
   в панели. Без сервера этот пункт не изображать как выполненный: показать сохранённый CSV.

## Почему Android выбран первым

Он соответствует телефонам, которые предполагается использовать в автопарке.
Установка подготовленного APK не требует Mac и переноса программы на iOS.
Внешняя камера не нужна для первой проверки локального анализа.
При этом ИК-съёмка в темноте остаётся отдельным следующим этапом, а не свойством обычной фронтальной камеры.

Официальные технические основания:
- [CameraX: запись и ограничения сочетания с анализом](https://developer.android.com/media/camera/camerax/video-capture).
- [Media3: RTSP, H.264, TCP и авторизация](https://developer.android.com/media/media3/exoplayer/rtsp).
- [Apple: установка на личное устройство через Xcode и ограничения Personal Team](https://developer.apple.com/help/account/basics/about-your-developer-account).

Сроки покупки, цена и совместимость Ethernet+зарядки зависят от конкретного Android.
Один разъём USB-C этого не гарантирует. Покупку внешней камеры имеет смысл делать после
успешного теста текущего APK на выбранном телефоне.
