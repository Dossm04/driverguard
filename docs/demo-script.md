# DriverGuard — сценарий показа менторам (5 минут)

Подготовка (один раз, ≤ 5 минут с нуля): `make demo` — поднимает PostgreSQL, MinIO, backend
(миграции + демо-данные), панель, PWA, симулятор устройства и Telegram-бота. Пока собирается,
откройте два окна: панель `http://localhost:3000` (admin@driverguard.kz / admin123) и
на телефоне или во втором окне 390px PWA `http://localhost:3000/driver` (+77012441832 / 1234).
Для реальной кабины вместо симулятора: `cd device && .venv/bin/python -m dg --source 0 --display`.

| Мин | Что показываем | Где | Что говорим |
|---|---|---|---|
| 0:00 | **Проблема и цифры парка** | Панель → Обзор | 6 машин, 14 событий сегодня (+3 к вчера), 3 критических, средний Score 78 при цели 80, 3 водителя в красной зоне. Всё считается по формуле из ТЗ, веса редактируются. |
| 0:40 | **Устройство ловит микросон** | Ноутбук с камерой: `python -m dg --source 0 --display` | Закрываем глаза на 2 секунды — сирена, событие «Засыпание за рулём» в SQLite, клип 15 с (10 до / 5 после). Моргание сиреной не считается — порог 1.5 с и подтверждение по кадрам. |
| 1:20 | **Авиарежим → накопление → сеть** | Терминал устройства | Отключаем Wi-Fi: события копятся (`pending` растёт, backoff 30 с → 10 мин). Включаем — батч уходит за секунды, дубликатов нет (upsert по uuid). Без камеры то же делает симулятор `device-sim`. |
| 2:00 | **События на карте и в ленте** | Панель → Live-карта, События | Маркеры двигаются по трассе Астана–Караганда через WebSocket, новое событие всплывает в ленте без перезагрузки. Фильтры по типу, водителю, статусу; клип в модалке; CSV с кириллицей. |
| 2:40 | **Review меняет Score** | События → «Ложное» на микросне Иванова → Лидерборд | Статус «Ложное» возвращает водителю баллы (55 → 73), кадр уходит в очередь дообучения, действие в аудите. Лидерборд пересчитан мгновенно. |
| 3:10 | **Лидерборд и профиль** | Лидерборд → карточка водителя | Подиум, серия дней без нарушений, бейджи, зачёт по депо; профиль: динамика Score по неделям, разбор по типам, назначение 30-секундного обучения. |
| 3:40 | **Чек-лист с ИИ** | PWA → Чек-лист (7 фото с камеры) → панель → Чек-листы | Мастер только с камеры, силуэт-подсказки, анкета из 42 пунктов; ИИ (Qwen/Gemini) сверяет фары, шины, стекло, утечки; вердикт «допущен / требует внимания / не допущен», расхождения анкеты и фото подсвечены координатору. |
| 4:20 | **SOS и Telegram** | PWA → SOS (удержание 3 с) → Telegram | Причина + координаты → критическое событие → алерт координатору с кнопками «Позвонить», «Подтвердить», «Ложное»; `/status` и `/leaderboard` в боте. |
| 4:50 | **Отчёты и настройки** | Отчёты → PDF; Настройки → Скоринг | PDF с кириллицей за 7 дней; веса скоринга и пороги устройства редактируются в панели, устройство подхватывает их без перезапуска, версия и автор в аудите. |

Чек перед показом: `make demo` зелёный, `make test` зелёный, `cd web && npx playwright test` — 25 сценариев,
обе темы (переключатель в топбаре), в Telegram введён chat_id (Настройки → Уведомления).

Нюанс: если в панели нажимали «Перезагрузить» у DG-0001, симулятор при следующем опросе конфига
завершится кодом 3 (так задумано — systemd/compose перезапустят его).

Запасные ходы: если нет камеры — только симулятор (события идут каждые ~10–30 с при
`--speedup 5`); если нет интернета для ИИ — `AI_PROVIDER=mock` даёт детерминированный вердикт;
если Telegram недоступен — `docs/telegram.md` §6, фейковый Bot API.
