# Чек-лист ежедневного осмотра автотранспортного средства — v2

Статус: **спецификация утверждена пользователем** (сессия 31.08.2026): 42 пункта,
из них 20 пунктов исходной формы пользователя — обязательное ядро (`base`), остальные —
добавки мирового уровня (`extra`, ориентиры: предрейсовый осмотр DOT/FMCSA, ЕСТР).
Реализация: backend + панель — ШАГ 10, мастер в PWA водителя — ШАГ 13.

## Правила вердикта

- Ответы: **Да / Нет / Н-П** (не применимо — только там, где помечено).
- `critical` + «Нет» → вердикт **«не допущен»** (выезд блокируется до устранения).
- `attention` + «Нет» → вердикт **«требует внимания»** (координатор решает).
- Все «Да» → **«допущен»**.
- 7 обязательных фото с ИИ-проверкой (Приложение В ТЗ) сохраняются; анкета дополняет их:
  пункты со способом «фото-ИИ» сверяются с вердиктом модели, расхождение подсвечивается.
- Способ: `авто` — заполняет система, водитель не тратит время; `ответ` — Да/Нет;
  `фото-ИИ` — входит в комплект из 7 фото; `ввод` — ручное значение.
